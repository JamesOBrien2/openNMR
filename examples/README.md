# Examples

## synthetic-ethanol

A simulated 1D proton spectrum generated by
`tools/reference/synthetic_1d.py`. It is synthetic data, not an experimental
measurement, and it is not a validation of all processing steps.

To open it in openNMR:

1. Choose **Open folder**.
2. Select `examples/synthetic-ethanol/1` — the folder that contains `fid`,
   `acqus` and `pdata`.
3. Do not select the `fid` file on its own.

Expected signals are at approximately 1.22, 2.61, 3.69, 7.26 and 0 ppm.
